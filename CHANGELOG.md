# Changelog

## [0.1.0] - 2026-01-09

### Added
- Core Engine with device abstraction
- Pipeline system for composable processing
- Base Module class with serialization
- ROCm and CUDA compute backends
- Memory management and profiling
- Training loop with Adam/SGD optimizers
- Dataset and DataLoader utilities
- Model serving with FastAPI
- CLI interface
- Transform utilities
- Callback system for training hooks
- Checkpoint saving
- ONNX export
- Metrics collection and monitoring
- Rate limiting middleware
- Test suite
- GitHub Actions CI
- Full API documentation
- ROCm integration guide
- Deployment guide

### Design Decisions
- AMD ROCm as primary GPU target for open-source alignment and cost efficiency
- MIT license to encourage community adoption
- Modular architecture for research and production
